# Dashboard UI/UX refinement — WeeklyReport, index.tsx, LineChart

This branch applies a visual/UX pass to the Statistics dashboard across three files. The core goal was hierarchy and clarity: remove ALL-CAPS section titles, enlarge primary metrics, compact the bar chart, replace topic chips with progress-bar rows, lighten card borders, and add sparse-data affordances. No business logic, hooks, calculations, or data structures were changed.

**Watch for:** `tbProgressRow`/`tbProgressFill`/`tbProgressTrack`/`tbRatePct` styles remain defined in `s = StyleSheet.create({})` after the corresponding JSX blocks were removed — orphaned style keys. Not a runtime issue but should be cleaned up.

**Verdict**: APPROVED

---

## High-level view

All twelve acceptance criteria for FEAT-001 and all sixteen for FEAT-002 are satisfied by inspection of the changed files. TypeScript check passes with zero new errors; the two `dominantBaseline` errors in `index.tsx:441,445` and the pre-existing errors in `add-task.tsx`, `AppText.tsx`, `NavigationBar.tsx`, and `useMotion.ts` are all confirmed pre-existing on master and not introduced by this branch. All 18 vitest tests pass.

The `sectionTitle` style in both files has `textTransform: 'uppercase'` fully removed. `statLabel` and `statCardLabel` in `index.tsx` correctly retain `textTransform: 'uppercase'` and `letterSpacing: 0.7`, preserving the TODAY/STREAK/TIME INVESTED/COMPLETED label treatment. Card borders use `StyleSheet.hairlineWidth` across `card`, `statBar`, and `progressCard` in `index.tsx` and `card` in `WeeklyReport.tsx`.

The four orphaned style keys (`tbProgressRow`, `tbProgressTrack`, `tbProgressFill`, `tbRatePct`) are defined in the StyleSheet but have no JSX references. This is harmless at runtime and has no effect on rendering, but represents unnecessary dead code.

`barsContainer.height` is 72 and max bar height formula uses 46. The `barEmptyState` view with "No activity this week" text renders correctly when all days have `completed === 0`.

Old chip-based topic list replaced with `topicBarList` vertical rows. Each row has a name, count, and a full-width `topicBarTrack`/`topicBarFill` progress bar using the topic color. Four old style keys (`topicList`, `topicChip`, `topicName`, `topicCount`) are absent from the StyleSheet.

`WebLineChart` dot-render now sets `isToday = i === (data?.length ?? 1) - 1`, radius 4 at rest for today vs 2.5 for other active points. Opacity is 1 for today or any active point, 0.35 for zero-value non-today points. The main `LineChart` export wraps the platform chart in a `<View>` and appends a `sparseTip` text when fewer than 5 data points are active, using `tokens.textMuted`.
